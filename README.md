# 逐句｜專注閱讀工具

一個協助閱讀障礙者與容易被密集文字干擾的讀者，逐句專注閱讀的網頁 Demo。

## 需求整理

### 文字處理

- 使用者可貼上中文或中英混合文字，或拖放／選擇本機檔案。
- 支援有文字層的 PDF，以及 TXT、Markdown、CSV／TSV、JSON、HTML、XML、YAML、SRT、VTT、LOG 等純文字格式。
- 單檔上限 40 MB；掃描圖片型 PDF 與其他需要 OCR 的檔案不支援。
- 系統依 `。！？!?；;…` 與換行自動分句，每句顯示為獨立一行。
- 保留句尾標點與引號，避免小數點被錯誤切開。

### 視覺輔助

- 所有句子都有固定的序號、間距與閱讀節奏。
- 可切換「高亮、底線、圓點」三種閱讀標記。
- 可選擇模糊非當前句，降低視覺干擾。
- 可調整閱讀字級。

### 互動與無障礙

- `Space` 或 `↓` 前往下一句，`↑` 返回上一句。
- 可直接用滑鼠或觸控點選任一句。
- 當前句會自動捲動到閱讀區中央，並顯示進度。
- 支援清楚的鍵盤焦點、語意標籤、螢幕閱讀器狀態播報與「減少動態效果」偏好。
- 文字與檔案只在瀏覽器本機處理；不會上傳、儲存或保留，關閉頁面後即消失。

### 檔案檢測

- 選擇檔案後會依序檢查格式、40 MB 容量限制與文字內容擷取。
- 成功時顯示檔案格式、大小、擷取字數與預估句數。
- 失敗時會區分不支援格式、容量超限、掃描型 PDF／PDF 無文字層、PDF 密碼保護、損毀檔案與文字編碼問題。

## 本機執行

```bash
npm install
npm run dev
```

## 驗證

```bash
npm test
npm run build
```

發布後可執行線上煙霧檢查，確認主頁載入正式建置結果，且 JavaScript、CSS、PDF worker 與隱私文案皆可取得：

```bash
npm run verify:deploy
```

## 技術

Vite + 原生 HTML、CSS、JavaScript，無後端、無資料庫。

本專案以 GitHub Pages 的「Deploy from a branch」模式發布，來源目錄必須設為 `/docs`。`npm run build` 會產生可直接部署的 `docs/` 內容。
